# Histogramme d’une image

Un **histogramme** représente la répartition des valeurs des pixels d’une image. Pour une image en niveaux de gris, les pixels ont des valeurs de **0 à 255**. L’histogramme indique combien de pixels possèdent chaque valeur.

```text
Image                    Histogramme
┌────┬────┬────┐
│ 10 │ 20 │ 20 │           hist[10] = 1
│ 30 │ 20 │ 50 │    →      hist[20] = 3
│ 10 │ 50 │ 50 │           hist[30] = 1
└────┴────┴────┘            hist[50] = 3
```

## 1. Fonction prédéfinie `cv2.calcHist()`

OpenCV permet de calculer automatiquement l’histogramme avec :

```python
hist1 = cv2.calcHist([im1], [0], None, [256], [0, 256])
```

Les paramètres sont :

```text
[im1]    → image à analyser
[0]      → canal à analyser
None     → aucun masque, toute l’image
[256]    → 256 classes (valeurs 0 à 255)
[0,256]  → intervalle des valeurs
```

Pour une image couleur `im2`, OpenCV utilise l’ordre **BGR** :

```text
[0] → Bleu
[1] → Vert
[2] → Rouge
```

Donc :

```python
hist2_B = cv2.calcHist([im2], [0], None, [256], [0, 256])
hist2_G = cv2.calcHist([im2], [1], None, [256], [0, 256])
hist2_R = cv2.calcHist([im2], [2], None, [256], [0, 256])
```

## 2. Affichage avec Matplotlib

On utilise :

```python
import matplotlib.pyplot as plt
```

Pour afficher `hist1` :

```python
plt.plot(hist1)
plt.title("Histogramme de im1")
plt.xlabel("Niveau de gris")
plt.ylabel("Nombre de pixels")
plt.show()
```

```text
Nombre de pixels
      ↑
      │       /\
      │   /\ /  \__
      │__/  \_______
      └────────────────→
        0          255
         Valeur du pixel
```

Pour les trois histogrammes de `im2` dans une seule fenêtre :

```python
plt.plot(hist2_B, label="Bleu")
plt.plot(hist2_G, label="Vert")
plt.plot(hist2_R, label="Rouge")
plt.legend()
plt.show()


`plt.plot()` trace la courbe, `plt.title()` donne le titre, `plt.xlabel()` et `plt.ylabel()` nomment les axes, `plt.legend()` affiche la légende et `plt.show()` affiche le graphique.
